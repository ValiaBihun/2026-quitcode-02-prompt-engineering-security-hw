# Документація публічного API quote.ts

## Роль

Technical writer з бекграундом TypeScript-розробника: пише API-документацію
для команди, яка буде викликати цей модуль, не читаючи його вихідний код.

## Мета

Створити `app/README.md`, що документує всі публічні експорти
`app/src/quote.ts` — сигнатуру, приклад виклику й інваріант, підтверджений
тестами — без жодної зміни коду.

## Контекст

- `app/src/quote.ts` — актуальна версія (після фіксів `add-tests`/`debug-quote`
  і рефакторингу `refactor-quote`): 3 експорти —
  `estimateTotalCents`, `splitInstallments`, `formatMoney`.
- `app/src/quote.test.ts` — джерело правди для інваріантів: що саме
  гарантовано, а що ні.
- `app/package.json` — скрипти `test` і `typecheck`.
- У `app/` наразі **немає** README — це прогалина, яку закриває цей промпт.

## Обмеження

- НЕ змінювати жоден `.ts` файл — лише `app/README.md`.
- НЕ документувати можливості, яких немає в коді (без вигаданих фіч, без
  розділів на кшталт CI/badges, яких у проєкті нема).
- Кожне твердження про поведінку має підтверджуватись конкретним тестом.

## Acceptance criteria

- [x] Документовано всі 3 експортовані функції та тип `QuoteInput`: сигнатура
      кожної функції + короткий приклад; для `QuoteInput` — опис полів
      `hours`, `rateCents`, `discountPercent`.
- [x] Наведено приклад об'єкта `QuoteInput` для виклику `estimateTotalCents`.
- [x] Явно згадано інваріанти з тестів: цілі центи; `discountPercent` 0..100
      інакше `RangeError`; сума `splitInstallments` точно дорівнює вхідній сумі.
- [x] Є секція «як встановити й запустити» (`npm install`, `npm test`,
      `npm run typecheck`).
- [x] `cd app && npm test` лишається зеленим — документація коду не чіпає.

## Формат відповіді

Готовий Markdown-файл `app/README.md`.

## Stop

Після README — зупинитись. Не редагувати `prompts/`, `src/` чи додавати нові
розділи понад те, що описано в Acceptance criteria.

## Результат реального запуску

**Знайдена прогалина:** у `app/` не було README — новий учасник команди мав би
читати вихідний код, щоб дізнатись сигнатури й інваріанти.

**Що зроблено:** [`app/README.md`](../app/README.md) — розділи «Встановлення і
запуск», «API» (3 функції + тип `QuoteInput` з описом полів і прикладами) і
«Інваріанти, підтверджені тестами»
(цілі центи, валідація `discountPercent`, збереження суми в
`splitInstallments`) — усі три факти напряму походять із `quote.test.ts`, нічого
не вигадано.

**Результат:** `cd app && npm test` → 12/12 тестів як були, так і лишились
зеленими — зміна суто документаційна, коду не торкались.
