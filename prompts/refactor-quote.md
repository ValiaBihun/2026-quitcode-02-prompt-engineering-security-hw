# Рефакторинг: іменовані константи замість magic numbers

## Роль

Senior TypeScript-розробник, що рефакторить лише заради читабельності — не
чіпаючи поведінку і не вигадуючи нових абстракцій.

## Мета

Знайти всі магічні числа в `app/src/quote.ts` і замінити на іменовані
константи там, де одне й те саме число (`100`) означає різні речі в різних
місцях — без жодної зміни результату будь-якої функції.

## Контекст

- `app/src/quote.ts` — три функції: `estimateTotalCents`, `splitInstallments`,
  `formatMoney`.
- `app/src/quote.test.ts` — 17 наявних тестів (`it`-блоків, станом на фінальну
  версію файлу); це regression-запобіжник: жоден результат не має змінитись.

## Обмеження

- НЕ змінювати публічний API і жоден результат функцій.
- НЕ чіпати `app/src/quote.test.ts` — якщо для рефакторингу довелось міняти
  тест, це вже не рефакторинг.
- НЕ вигадувати нових абстракцій/файлів/хелперів понад те, що потрібно для
  найменування вже наявних магічних чисел.

## Acceptance criteria

- [x] Кожне використання літералу `100` замінено на семантично іменовану
      константу (в `formatMoney` — центи в доларі; в `estimateTotalCents` —
      шкала відсотків) — це два різні поняття під однаковим числом.
- [x] `app/src/quote.test.ts` лишився без жодної правки.
- [x] `cd app && npm test` — усі 17 тестів як були, так і лишились зеленими.
- [x] Діф обмежений `app/src/quote.ts`.

## Формат відповіді

Спершу список знайдених magic numbers і що вони насправді означають, потім діф.

## Stop

Після зелених тестів без правок у test-файлі — зупинитись. Не рефакторити
структуру `splitInstallments`/`formatMoney` — це вже вихід за межі задачі.

## Результат реального запуску

**Знайдені magic numbers:** літерал `100` зустрічався у двох місцях з різним
змістом:
- `estimateTotalCents`: `(gross * discountPercent) / 100` — тут `100` означає
  «шкала відсотків» (percent scale).
- `formatMoney`: `Math.floor(abs / 100)` і `abs % 100` — тут `100` означає
  «центів в одному доларі» (cents per dollar).

Однакове число з різним змістом у двох місцях — типовий привід для іменованих
констант, навіть без зміни поведінки.

**Що зроблено:** додано `CENTS_PER_DOLLAR = 100` і `PERCENT_SCALE = 100` на
рівні модуля [`app/src/quote.ts`](../app/src/quote.ts), замінено відповідні
літерали.

**Результат:** `cd app && npm test` → 17/17 тестів зелені, `app/src/quote.test.ts`
не змінювався — поведінка байдуже ідентична, змінилась лише читабельність.
